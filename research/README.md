# Research

- `findings/` — measurements, layout reviews, and decision records for the
  current model and shipped layout.
- `plans/` — historical task lists and implementation plans. These are kept as
  project history; some commands and paths may refer to earlier repository
  layouts.
- `sources/` — archived external analyzer pages, layout notes, and reference
  material used during research.

Current layout decisions are summarized in `layouts/shiro/README.md`.
